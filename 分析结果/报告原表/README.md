## 2. 关键新发现（原始CSV中不存在的信息）

### 2.1 降雨量数据（表5.1-2）—— 补齐环境链关键一环

| 指标 | QXZ-YK665+835 | QXZ-ZK658+005 |
|---|---|---|
| 雨量最大值 | 4.6 mm/h | **6.8 mm/h** |
| 雨量最大值时间 | 2025-11-08 04:00 | 2025-11-08 08:00 |
| 雨量均值 | 0.08 mm/h | 0.04 mm/h |
| 雨量标准差 | 0.34 | 0.26 |
| 零星小雨 | 1611次 | 1662次 |
| 小雨 | **166次** | **135次** |
| 中雨 | 27次 | 7次 |
| 大雨及以上 | 0 | 0 |

**结论**：
1. 试运行报告的"降雨166/135次"确认为**小雨次数**，此前资料综述中的表述已修正；
2. 最大雨强仅 4.6~6.8 mm/h（中雨量级），全期无大雨/暴雨，**2025-11-08 为唯一明显降雨峰值**；
3. 洞外气象站设计含降水传感器（表7-2：0~4mm/min），但导出CSV无雨量列——**数据在平台/报告层，未进入导出文件**。论文如需逐时降雨序列，应向平台方导出雨量字段；
4. 本次以"湿度≥98% 且能见度≤5km"构建的降雨代理（YK站84天、ZK站34天）与报告雨日统计量级一致，可用于日尺度降雨-流量分析，但不可替代逐时雨量。

### 2.2 气压单位问题
报告表5.1-1 标为"气压/hpa"，数值 96.8~99.6；若为 hPa 则约为标准气压的 1/10，实际应为 **kPa（97~100kPa）**，属单位标注错误。论文引用时写"气压约97~100 kPa"。

### 2.3 报告统计覆盖 vs 设备清单（重要差异）

| 项目 | 设备清单/设计 | 报告表统计 | 差异原因（推断） |
|---|---|---|---|
| 渗压计 | 8支 | 5支 | 报告窗内仅5支有效（YK659+165、YK659+210、ZK659+266 未纳入） |

| 激光 | 144台 | 143站 | 1站无有效数据（对应 ZBW-YK659+620-YGY-02 错误码58%） |

> 论文写法建议：正文以设备清单的 8/8/144 为系统规模，统计表注明"报告窗内有效测点数"。

### 2.4 温度相关系数与本次复算的差异
报告表3.3-1 给 ZBW-ZK663+900-YGY-01 r=0.8516、ZK664+960-YGY-01 r=0.8447；本次全期（至2026-03-19）复算为 0.866 / 0.821。差异来自统计窗（报告仅11–1月）与清洗规则不同，**结论方向一致**，引用时注明窗口即可。
