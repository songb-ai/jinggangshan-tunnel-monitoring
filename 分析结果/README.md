## 3. 超出报告的新发现（论文创新素材）

1. **速率判据误报机理**：设计表7-19速率/3日判据源于人工低频监测经验，直接套用于10min高频数据会系统性误报（激光78站字面"报警"）；须先做温度效应分离 → 预警规则优化核心证据
2. **2025-12-12全隧道基准跳变定量**：中位-85.7mm（144站同步），变形分析必须以2025-12-12为基准日
3. **应变温度响应的断面弯曲模式**：同断面左右拱腰 r 符号相反（ZK663+740：-0.91 vs +0.88）
4. **洞内环境沿程衰减规律**：变幅比与滞后随埋深单调变化（洞口0h→深埋15h）
5. **ZK663+740~780 多源互证最活跃区段**：应变极差前2 + 视觉极差前6 + 激光相关点名，均落该区段；但视觉日序列有±5~35mm锯齿阶跃，疑测量链不稳定，需现场核查
6. **阈值体系盲区**：pH仅设酸侧阈值，实测碱性达12.03无判据可依；建议论文补全碱侧预警讨论
7. **设计风险等级与实测响应互证**：ZK663+700~664+020 为设计"较大风险"区段（含拱顶空洞、厚度不足、环向裂缝），恰为应变/机器视觉/激光实测最活跃段——可作为"风险辨识有效性"的闭环证据（详见设计文件表格汇编 §5.2）
8. **雨量统计补齐降雨链**：报告表5.1-2确认最大雨强4.6/6.8mm/h（2025-11-08），小雨166/135次，中雨27/7次，无大雨以上；全期降雨以零星小雨为主（详见 报告原表/README.md）
